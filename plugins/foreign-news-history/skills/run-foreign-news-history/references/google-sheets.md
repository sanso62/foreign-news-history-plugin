# Google Sheets 동기화

## 대상

- 스프레드시트: `외신 일일동향`
- ID: 설치 환경의 연결 계정에서 실행할 때 확인
- 원본 탭: `작업내역`, `A:K` 읽기 전용
- 근무 탭: `근무`, 읽기 전용. 고정 범위를 사용하지 않고 매 실행 현재 그리드에서 `동향 스케줄` 제목과 표 헤더를 찾아 작업일 요일의 담당자 근거를 조회
- 결과 탭: 작업일의 월을 사용한 `{month}월`, `A:O`

문서 ID는 배포 패키지에 저장하지 않는다. 실행할 때 연결 프로필에서 `외신 일일동향`을 찾고 스프레드시트 메타데이터를 읽어 이름·헤더가 맞는지 확인한다. 같은 이름의 문서가 여러 개이면 사용자에게 선택을 요청한다.

## 읽기

전체 시트를 무제한으로 가져오지 않는다. 메타데이터의 실제 그리드 행 수와 `A:K` 11열을 기준으로 한 번에 5만 셀 이하인 겹치지 않는 유한 A1 범위를 만든다. 각 범위를 반드시 `FORMATTED_VALUE`로 읽고 원시 응답의 실제 `range`와 `values`를 로컬 JSON에 보존한다. `search_spreadsheet_rows`의 날짜 문자열 검색으로 대상 행을 수집하지 않는다. 표시값이 `2026. 7. 22`인데 `2026-07-22`를 검색하면 날짜 셀은 빠지고 URL에 해당 문자열이 든 일부 행만 남을 수 있기 때문이다.

모든 범위의 헤더와 행을 원본 순서로 합친 뒤 `scripts/prepare_source_history.py`에 작업일 전날 ISO 날짜를 전달한다. 이 스크립트가 표시 날짜를 로컬에서 파싱해 대상 행만 고르고, `source_audit`에 `bounded_range_scan`, `FORMATTED_VALUE`, 실제 스캔 범위, 스캔·일치 행 수를 기록한 `정기작업내역.json`을 만든다. 감사정보가 없거나 날짜 검색 결과인 입력은 `process_job.py`가 거부한다.

`근무` 탭은 매 실행 먼저 메타데이터로 실제 탭 이름, `sheetId`, 그리드 행·열 수를 확인한다. 메타데이터가 가리키는 그리드를 `assets/harness.config.json`의 `schedule_scan_max_cells` 이하 청크로 나누어 `동향 스케줄`과 정확히 일치하는 셀을 찾는다. 청크는 서로 겹치지 않게 조회하고 빈 검색어나 전체 그리드 단일 조회를 사용하지 않는다. 제목 셀을 찾으면 그 주변의 작은 범위를 읽어 아래쪽에 `보고서`, `구분`, 최종보고서 작업일의 요일, 최소 5개의 요일 헤더가 함께 있는지 확인한다. 유효한 표가 없거나 둘 이상이면 범위를 추측하지 않고 중단한다.

확인된 표 범위와 해당 조회 응답을 로컬 JSON에 보존하고, 최종보고서 작업일로 요일을 계산해 `scripts/select_schedule.py`에 정확한 A1 조회 범위를 전달한다. 선택 결과에는 스프레드시트 ID, 탭, 실제 조회 범위, 표 제목·헤더 셀, 원본 행 번호와 보고서·구분·발행 요일·담당자 셀을 보존한다. `scripts/process_job.py`는 이 동적 출처 정보가 없는 구형 스케줄 JSON을 거부한다. 이 자료는 작업조·초벌 담당·초벌 작업자·최종 담당·최종 작업자의 필수 근거이며 `작업내역` 및 `근무` 탭에는 쓰지 않는다.

## 쓰기 전 검사

1. 로컬 중간 엑셀과 `checkpoint.json`의 `intermediate_saved`를 확인한다.
2. `checkpoint.json`의 `review_rows`가 0인지 확인한다. 한 건이라도 남아 있으면 쓰기를 중단한다.
3. 월별 탭 `A1:O1`이 결과 스키마와 정확히 같은지 확인한다.
4. 월별 탭에서 같은 작업일 행을 조회한다.
5. 기존 행이 없으면 추가한다.
6. 기존 행이 새 결과와 같으면 쓰지 않고 성공으로 기록한다.
7. 기존 행이 새 결과와 다르면 자동 수정·삭제하지 않고 사용자 승인 요청으로 중단한다.

## 쓰기와 검증

헤더는 쓰지 않고 데이터 행만 한 번의 연속 범위로 추가한다. 쓰기 직후 해당 범위를 재조회하여 행 수와 모든 `A:O` 값을 비교한다. 정확히 같을 때만 체크포인트를 `uploaded_verified`로 변경한다.

원본 탭 `작업내역`에는 어떠한 쓰기·정렬·서식 변경도 하지 않는다.

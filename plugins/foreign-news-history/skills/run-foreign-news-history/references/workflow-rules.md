[일일외신보도동향 작업 이력표 작성 기준]

1. 최종보고서 기준
- 작업 이력표에 입력하는 제목은 반드시 최종보고서 첫 장의 제목 목록을 최우선 기준으로 한다
- 일반기사·첫 장에 실제 기재된 유사보도는 첫 장 제목을 그대로 입력한다
- 약칭, 따옴표, 띄어쓰기, 숫자 표기 등을 임의로 풀어 쓰거나 다듬지 않는다
- 최종보고서 첫 장 제목과 본문 제목이 다르면 첫 장 제목을 우선한다
- 첫 장에서 확인되지 않는 유사·미포함 기사는 본문 제목, 실제 초벌 원본 제목, 같은 작업일의 권위 있는 기준표 순으로 확인한다
- 작업본 제목과 최종보고서 제목이 다르면 최종보고서 제목으로 교체한다

2. 카테고리
- 최종보고서 첫 장의 상위 카테고리를 입력한다
- [한-아세안 외교장관회의]처럼 상위 카테고리 아래에 배치된 하위 항목은 카테고리로 입력하지 않는다
- 해당 기사에는 외교·안보처럼 실제 상위 카테고리를 적용한다
- 일본동향 등 초벌 파일의 카테고리가 최종보고서와 다르면 최종보고서 상위 카테고리로 통일한다
- 최신 오전 총괄본이 최종 상위 카테고리를 포함하는 확장 표기로 합친 경우에만 그 최신 표기를 반영하고, 서로 다른 카테고리로 이동한 것처럼 보이는 파싱 결과는 덮어쓰지 않는다
- 새 카테고리를 임의로 만들거나 기존 카테고리를 임의로 축약하지 않는다

3. 초벌 담당·작업자
- 전일 밤 오후폴더의 개별 국내 초안에서 처음 들어온 기사는 `1조/국내`, 글로벌 이슈 작업본에서 처음 들어온 기사는 `1조/글로벌`로 기록한다
- 오후 취합본은 `오후/오후/총괄`로 기록하되, 개별 초안에도 있는 기사의 최초 유입 경로를 취합본으로 바꾸지 않는다
- 당일 새벽 오전폴더의 보조·개별 초안에서 처음 들어온 기사는 `2조/보조`로 기록한다
- 오전 `1차·2차·3차·n차·최종` 총괄본은 `2조/오전/총괄`로 기록하되, 오후 파일에도 있는 기사의 최초 유입 경로를 오전으로 바꾸지 않는다
- 최신 오전 총괄본에서 처음 확인된 전일자 기사는 `1조/오후/총괄`로 기록한다
- 작업자는 파일명에 표시된 이름과 같은 역할의 당일 `0. 근무 일정` 행이 일치할 때만 확정한다. 역할 표기와 사람 이름을 분리하며, 과거 날짜의 사람별 역할을 재사용하지 않는다
- 정기 유입은 작업조에 정기 경로를 표시하되, 초벌 담당과 초벌 작업자는 당일 정기 기사를 실제 편집한 취합 단계와 작업자로 입력한다
- 같은 기사가 정기 작업내역과 당일 외신동향의 개별 국내·글로벌 초안에 모두 있으면, 자동 기준 이상으로 동일 기사임이 확인된 실제 동향 초안을 우선해 해당 초안의 작업조·담당·작업자를 기록한다. 개별 초안 제목이 크게 수정된 경우에는 같은 매체·날짜의 초안 후보가 하나뿐이고 의미 있는 제목 일부가 남아 있으며 후속 취합본이 최종 제목을 자동 기준 이상으로 이어받았을 때만 같은 중복으로 인정한다. 오후·오전 취합본 자체는 이 중복 우선 규칙의 작업 경로가 아니다
- 일본언론동향 유입은 작업조에 일본동향의 기관·경로를 표시하되, 초벌 담당과 초벌 작업자는 당일 실제 편집 단계와 작업자로 입력한다
- 정기 내역과 일본언론동향 양쪽에 모두 있으면 초벌 경로는 정기를 우선한다
- 다만 일본언론동향에도 포함된 기사는 일일일본동향 여부를 O로 유지한다
- 정기·일본동향 어디에도 없는 최종보고서 기사는 총괄·국내·글로벌·보조 등 다른 파일에서 유입 경로를 확인한다
- 유입 경로를 확인하지 못한 경우 추측하지 않고 확인 필요로 표시한다

3-1. 작업조·최종 담당 표기
- 정기 유입의 작업조는 `정기`, 초벌 담당은 `오후/총괄`, 초벌 작업자는 당일 오후 취합 작업자로 기록한다
- 예외적으로 `작업날짜`가 대상 정기일과 같고 `보도일`은 정확히 하루 전인 정기 기사가 오후 입력 어디에도 없으며, 오전 개별·보조 초안에도 없고 완전한 오전 총괄본에서 자동 기준 이상으로 처음 재확인된 경우에는 작업조 `정기`를 유지하고 초벌 담당·작업자는 그 최초 오전 총괄본의 `오전/총괄/<작업자>`로 기록한다. 조건 중 하나라도 확인되지 않으면 이 예외를 적용하지 않는다
- 일본언론동향 유입의 작업조는 `일본문화원`으로 기록하고, 초벌 담당·작업자는 일본동향 전체 기사 묶음을 가장 완전하게 취급한 당일 작업본과 근무표에서 판정한다. 기사별 저점수 우연 매치로 묶음 안에 서로 다른 담당자를 만들지 않는다
- 순방 업무가 파일에 명시된 경우 작업조는 `순방`으로 기록하고, 담당·작업자는 실제 파일 단계와 당일 근무표로 판정한다
- 대표기사의 최종 담당은 `오전/총괄`, 최종 작업자는 당일 오전 총괄 작업자로 기록한다
- 유사보도와 완전 미포함 기사의 최종 담당은 `최종 보고서 미포함`으로 기록하되, 최종 작업자는 동일한 당일 오전 총괄 작업자를 기록한다
- `오전/총괄`과 `오후/총괄`은 사람이 아니라 편집 단계 표기다

4. 최종보고서 포함 여부
- 최종보고서에서 날짜와 본문을 갖춘 대표기사로 수록된 경우 O로 입력한다
- 대표기사 아래에 제목만 붙은 유사보도는 최종보고서 포함 여부를 X로 입력한다
- 최종보고서 첫 장에 제목이 있다는 이유만으로 독립 본문 기사로 판단하지 않는다
- 본문 수록 형태를 함께 확인해 대표기사와 유사보도를 구분한다

5. 유사보도
- 별표가 붙어 있고 날짜와 본문이 없으며 직전 대표기사 아래에 배치된 항목은 유사보도 O로 처리한다
- 초벌 파일에서 유사보도로 확인된 기사가 취합 과정에서 별표만 빠졌더라도 날짜·본문·배치 구조가 같으면 유사보도 성격을 유지한다
- 첫 장의 한 대표 제목에 매체가 `/`로 묶였으면 매체 기재 순서의 첫 기사를 대표로 보고, 같은 묶음의 뒤 기사들은 날짜·본문·별표 유무와 관계없이 유사보도로 유지한다
- `/` 묶음 대표 제목이 첫 매체의 본문 기사와 의미상 대응하지 않으면 첫 본문 제목은 유지하고 묶음·유사 구조만 적용한다
- 최신 오전 총괄본에서 대표기사 바로 뒤의 명시적 유사보도가 확인되지만 최종 본문 추출에는 없으면 현재 원본 매칭으로 대표기사 뒤에 별도 행을 복구한다
- 최종보고서에 별표가 없고 형식도 불명확하면 확정하지 말고 편집상 예외 또는 확인 필요로 보고한다
- 유사보도도 삭제하지 않고 작업 이력표에서 별도의 한 행으로 유지한다
- 유사보도 제목 역시 최종보고서 첫 장 제목을 기준으로 입력한다

6. 날짜
- 날짜는 최종보고서 본문의 기사 제목 줄을 기준으로 입력한다
- 유사보도 제목 줄에 날짜가 없으면 매칭된 정기·일본동향·실제 초벌 원본의 날짜를 사용하고, 모든 현재 원본에도 날짜가 없을 때만 없음으로 입력한다
- 초벌 파일과 최종보고서 날짜가 다르면 최종보고서 본문 날짜를 우선한다

7. 파일 비교
- 작업자 초벌 파일 여러 개가 한 묶음이면 모두 통합해 취합본과 비교한다
- 동일 파일의 중복 업로드는 해시와 내용을 확인해 한 파일로 취급한다
- 비교 순서는 제목 전체 대조 → 의미상 동일 기사 확인 → 카테고리 이동 확인 → 유사보도 전환 확인 → 누락 여부 확정으로 한다
- 결과는 포함, 제목 수정 후 포함, 카테고리 이동 후 포함, 유사보도 처리, 누락, 중복 정리로 제외로 구분한다
- 없어지거나 누락된 항목이 있으면 일부만 제시하지 말고 전체를 먼저 제시한다

7-1. 최종보고서 유입 경로 비교 순서
- 최종보고서의 각 기사는 반드시 최초 유입의 시간 순서로 확인한다: ① Google Sheets 정기 작업내역과, 제공된 경우 사용자가 지정한 일본언론동향 원본 ② 전일 밤 오후폴더 ③ 당일 새벽 오전폴더
- ① 단계에서 정기 작업내역과 제공된 일본언론동향을 대조한다. 양쪽에 모두 있는 기사는 정기 경로를 유입 경로로 선택하고 `일일일본동향`은 O로 유지한다
- 정기 작업내역과 당일 외신동향의 개별 국내·글로벌 초안에 같은 기사가 중복되면 자동 기준 이상으로 일치한 실제 동향 초안을 우선한다. 취합·총괄본은 복사 단계이므로 이 예외로 정기 경로를 덮어쓰지 않는다
- 위 직접 동향 초안 중복 예외를 제외하면, 현재 단계에서 기준 점수 이상의 후보를 찾았다는 이유만으로 뒤 단계의 취합·총괄본이 더 높은 점수를 받아도 유입 경로를 바꾸지 않는다
- 오전폴더와 오후폴더의 구분은 사용자가 명시한 입력 경로로 판정하며 파일명, 작업자 이름, `source_kind`, 실행별 `priority`로 단계를 뒤바꾸지 않는다
- 같은 단계 안의 후보가 경합하면 현재 파일의 취합 관계와 매칭 점수를 함께 확인하고, 확정 근거가 부족하면 `확인 필요`로 둔다
- 현재 원문을 직접 대조한 실행별 `article_origin_confirmations`만 이 자동 선택을 교정할 수 있으며 구체적 근거를 기록한다

8. 중복기사
- 같은 URL, 같은 매체, 실질적으로 같은 제목과 내용이면 중복 여부를 확인한다
- 정기 작업내역과 당일 외신동향의 실제 개별 초안이 중복되면 동향 초안을 작업 경로로 우선하고, 정기 내역의 존재만으로 동향 작업자를 덮어쓰지 않는다
- 단순 중복은 한 건으로 대응하되 최종보고서에 별도 항목으로 남은 유사보도는 각각 유지한다
- 같은 매체라도 제목·기자·내용이 다르면 서로 다른 기사로 판단한다
- 같은 URL이더라도 제목이나 매체가 다르면 임의로 삭제하지 않고 확인 필요로 표시한다
- 중복 정리 후에도 제목은 최종보고서 첫 장 표기를 적용한다

9. 일본언론동향
- 일본언론동향은 선택 입력이다. 제공되지 않은 작업일에는 일본동향 비교를 건너뛰고 `일일일본동향` 열을 공란으로 유지하며, 미제공 자체를 확인 필요 사유로 만들지 않는다
- 일본언론동향 기사가 최종보고서에 수록됐는지 전부 대조한다
- 정기 내역에 없고 일본언론동향에만 있으면 일본동향 작업으로 판정한다
- 일본언론동향 파일의 자체 분류보다 최종보고서 상위 카테고리를 우선한다
- 일본언론동향에 포함된 기사는 일일일본동향 여부 O로 표시한다
- 일본언론동향 원본을 확인했더라도 수록되지 않은 기사는 일일일본동향을 X가 아니라 공란으로 둔다
- 제목 점수가 낮더라도 같은 매체이고 기사 날짜가 하루 이내인 일본동향 후보가 하나면 두 원문을 직접 대조하기 전까지 확인 필요로 둔다

10. 매체명
- 최종보고서 매체명 앞에 한글·한자 국가 또는 출처 접두어가 붙고 뒤에 영문 매체명이 있으면 접두어를 제외한 매체명만 입력한다
- 매체 별칭 사전을 만들지 않고 현재 문서 표기에서 접두어 구조가 확인되는 경우에만 적용한다

11. 오전·오후 취합 비교
- 작업자 원본의 모든 기사가 취합본에 포함됐는지 확인한다
- 제목 유지·수정, 카테고리 유지·이동, 유사보도 처리, 삭제·누락을 각각 구분한다
- 취합본에서 별표가 사라졌더라도 원본의 유사보도 조건과 최종 배치 구조를 함께 확인한다
- 취합 과정에서 새로 추가된 기사나 유사보도도 별도로 보고한다
- 오후 취합본의 기사가 오전 취합본까지 유지된 뒤 최종에서 빠졌으면 `1조/오후/총괄`의 완전 미포함 행으로 남기고, 한 취합 단계에만 잠시 나타난 기사는 자동 추가하지 않는다

- 최종보고서·작업자 파일 또는 제공된 일본동향의 파싱 오류·기사 0건은 치명적 입력 오류로 처리하고, 다른 파일의 취합본으로 대체 판정하지 않는다
- 모든 제목을 최종보고서 첫 장과 다시 대조한다

- 상위 카테고리가 아닌 하위 항목이 입력되지 않았는지 확인한다
- 초벌 담당·작업자와 일일일본동향 여부가 서로 모순되지 않는지 확인한다

# 외신동향 작업이력 Codex 플러그인

일일외신보도동향 작업본과 최종보고서를 비교해 기사별 작업이력을 만들고, 검수된 최종 엑셀로 저장하는 Codex 플러그인입니다.

## 설치

이 저장소는 공개 Codex 플러그인 마켓플레이스입니다. GitHub 협업자 초대나 저장소 접근 권한 없이 추가할 수 있습니다.

ChatGPT 데스크톱 앱에서 플러그인 디렉터리를 열고 **플러그인 마켓플레이스 추가**를 선택합니다.

- 출처: `sanso62/foreign-news-history-plugin`
- Git ref: `main`
- Sparse 경로: 비워 둡니다.

마켓플레이스를 추가한 뒤 **외신동향 작업이력**에서 `foreign-news-history` 플러그인을 설치하고 새 작업을 시작합니다.

## 업데이트

제작자가 새 버전을 게시한 뒤 설치자는 마켓플레이스를 업그레이드하고 새 작업을 시작합니다.

현재 배포 버전은 `v0.1.16`입니다. 입력은 `[VT] 2026년 24시간 외신 모니터링 및 요약 보고`의 `1. 작업 내역`과 `0. 근무 일정`에서 읽습니다. 일본언론동향은 선택 입력이며, 없는 작업일에는 비교를 건너뛰고 `일일일본동향` 열을 공란으로 유지합니다. 시험 운영 기간에는 결과 문서 `[VT] 2026년 일일동향보고 리스트`를 조회하거나 수정하지 않고, 확인 필요 행을 모두 해소한 `작업이력_최종.xlsx`를 최종 산출물로 저장합니다. `1. 작업 내역`은 표시 날짜 문자열 검색 대신 메타데이터 경계 안의 `A:O` 전체를 유한 범위로 읽고 로컬에서 대상일을 파싱하며, 설정된 입력 문서·탭과 다른 감사정보는 거부합니다. 결과 시트 쓰기는 설정의 `sync.google_sheets_write_enabled`가 명시적으로 `true`이고 사용자가 반영을 요청한 실행에서만 사용할 수 있습니다. 실행별 확인값은 반드시 재처리 결과에 반영하며 생성된 결과와 엑셀을 서로 다르게 수동 교정하지 않습니다. 최종보고서 기사의 기본 유입 경로는 다음 시간 순서로 비교합니다.

1. Google Sheets 정기 작업내역과, 제공된 경우 사용자가 지정한 일본언론동향 원본
2. 전일 밤 오후폴더
3. 당일 새벽 오전폴더

앞 단계가 자동 판정 기준을 충족하면 뒤 단계의 복사본이나 실행별 우선순위가 선택을 덮어쓰지 않습니다. 앞 단계가 자동 기준 미만일 때만 자동 기준 이상의 개별 초안이 판정 여유폭 이상 강한 경우 해당 초안 계보를 사용합니다. 정기 작업내역과 일본언론동향 양쪽에 모두 있으면 정기 경로를 선택하고 `일일일본동향=O`는 유지하되, 현재 원문을 직접 대조한 확인값은 일본 원문 유입을 확정할 수 있습니다.

```powershell
codex plugin marketplace upgrade foreign-news-history
```

## 데이터와 설정

플러그인에는 개인 이름, 작업 결과물, Google Sheets 문서 ID·URL 또는 인증 정보가 포함되지 않습니다. 실행 시 연결된 Google 계정에서 입력 문서 이름을 찾고 탭·헤더 구조로 검증합니다. 같은 이름의 후보를 구조로 하나까지 확정할 수 없으면 임의 선택하지 않고 사용자 확인을 요청합니다.

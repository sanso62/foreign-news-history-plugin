# 외신동향 작업이력 Codex 플러그인

일일외신보도동향 작업본과 최종보고서를 비교해 기사별 작업이력을 만들고, 중간 엑셀 검수 후 Google Sheets에 반영하는 Codex 플러그인입니다.

## 설치

이 저장소는 공개 Codex 플러그인 마켓플레이스입니다. GitHub 협업자 초대나 저장소 접근 권한 없이 추가할 수 있습니다.

ChatGPT 데스크톱 앱에서 플러그인 디렉터리를 열고 **플러그인 마켓플레이스 추가**를 선택합니다.

- 출처: `sanso62/foreign-news-history-plugin`
- Git ref: `main`
- Sparse 경로: 비워 둡니다.

마켓플레이스를 추가한 뒤 **외신동향 작업이력**에서 `foreign-news-history` 플러그인을 설치하고 새 작업을 시작합니다.

## 업데이트

제작자가 새 버전을 게시한 뒤 설치자는 마켓플레이스를 업그레이드하고 새 작업을 시작합니다.

현재 배포 버전은 `v0.1.8`입니다. `작업내역`은 표시 날짜 문자열 검색 대신 메타데이터 경계 안의 `A:K` 전체를 유한 범위로 읽고 로컬에서 대상일을 파싱하며, 감사정보 없는 부분 조회 입력은 거부합니다. 최신 작업본의 `/` 묶음 대표 제목과 암시적 하위 기사 표기를 최종 결과에 보존합니다. 개별 국내·글로벌 초안이 정기 후보보다 유의미하게 강할 때는 직접 초벌 근거로 판정하고, 유사보도 대표행이 동일 초안 흐름 사이에 삽입된 구조도 추적합니다. 직접 확인된 일본 원문은 크게 바뀐 정기 제목 추정보다 우선합니다. 최종보고서 기사의 기본 유입 경로는 다음 시간 순서로 비교합니다.

1. Google Sheets 정기 작업내역과 사용자가 지정한 일본언론동향 원본
2. 전일 밤 오후폴더
3. 당일 새벽 오전폴더

앞 단계에서 기준 이상의 후보를 찾으면 뒤 단계의 단순 고점수나 실행별 우선순위가 선택을 덮어쓰지 않습니다. 다만 현재 개별 초안의 직접 일치가 앞 단계보다 자동 판정 여유폭 이상 강한 경우만 해당 초안 계보를 사용합니다. 정기 작업내역과 일본언론동향 양쪽에 모두 있으면 정기 경로를 선택하고 `일일일본동향=O`는 유지하되, 현재 원문을 직접 대조한 확인값은 일본 원문 유입을 확정할 수 있습니다.

```powershell
codex plugin marketplace upgrade foreign-news-history
```

## 데이터와 설정

플러그인에는 개인 이름, 작업 결과물, Google Sheets 문서 ID 또는 인증 정보가 포함되지 않습니다. 실행 시 연결된 Google 계정에서 `외신 일일동향` 문서를 찾으며, 같은 이름의 문서가 여러 개이면 사용자가 대상을 선택해야 합니다.

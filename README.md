# 외신동향 작업이력 Codex 플러그인

일일외신보도동향 작업본과 최종보고서를 비교해 기사별 작업이력을 만들고, 중간 엑셀 검수 후 Google Sheets에 반영하는 Codex 플러그인입니다.

## 설치

이 저장소는 공개 Codex 플러그인 마켓플레이스입니다. GitHub 협업자 초대나 저장소 접근 권한 없이 추가할 수 있습니다.

ChatGPT 데스크톱 앱에서 플러그인 디렉터리를 열고 **플러그인 마켓플레이스 추가**를 선택합니다.

- 출처: `sanso62/foreign-news-history-plugin`
- Git ref: `main`
- Sparse 경로: 비워 둡니다.

마켓플레이스를 추가한 뒤 **외신동향 작업이력**에서 `foreign-news-history` 플러그인을 설치하고 새 작업을 시작합니다.

## 업데이트

제작자가 새 버전을 게시한 뒤 설치자는 마켓플레이스를 업그레이드하고 새 작업을 시작합니다.

현재 배포 버전은 `v0.1.14`입니다. 입력은 `[VT] 2026년 24시간 외신 모니터링 및 요약 보고`의 `1. 작업 내역`과 `0. 근무 일정`에서 읽고, 검증된 결과는 별도 문서 `[VT] 2026년 일일동향보고 리스트`의 월별 탭에 기록합니다. `1. 작업 내역`은 표시 날짜 문자열 검색 대신 메타데이터 경계 안의 `A:O` 전체를 유한 범위로 읽고 로컬에서 대상일을 파싱하며, 설정된 입력 문서·탭과 다른 감사정보는 거부합니다. `/` 묶음 대표 제목은 첫 본문 기사와 대응할 때만 적용하고, 최신 오전 총괄본의 명시적 유사보도와 오후·오전 취합 단계를 모두 통과한 최종 미포함 기사를 자동 복구합니다. 최신 총괄본의 카테고리는 최종 상위 카테고리와 호환되는 확장 표기일 때만 반영합니다. 자동 기준을 충족한 정기·일본 후보는 뒤에서 복사된 초안보다 우선하며, 정기·일본 후보가 검수 기준 미만이고 개별 초안이 명확히 우세할 때는 불필요한 낮은 점수 검수를 만들지 않습니다. 의미를 유지한 채 크게 재번역된 정기 기사는 복사·취합 작업본보다 앞선 유입으로 복원하며, 매체 표기가 번역되거나 축약된 경우에도 같은 날짜의 제목 후보가 유일하게 크게 앞설 때만 별칭표 없이 판정합니다. 단, 매체 근거가 다른 정확한 오전 보조 초안과 직접 오후 초안의 계보는 유지합니다. 같은 매체의 일본 원문이 유일하고 재번역 유사도가 충분하면 일본 유입과 일본동향 포함 여부를 함께 복원하며, 무관한 저점수 후보는 검토 대상으로 올리지 않습니다. 유사보도 대표행의 초안 계보는 취합본의 즉시 인접 경계로만 추적합니다. 실행별 확인값은 반드시 재처리 결과에 반영하며, 생성된 결과·엑셀·Google Sheets 값을 서로 다르게 수동 교정하지 않습니다. 최종보고서 기사의 기본 유입 경로는 다음 시간 순서로 비교합니다.

1. Google Sheets 정기 작업내역과 사용자가 지정한 일본언론동향 원본
2. 전일 밤 오후폴더
3. 당일 새벽 오전폴더

앞 단계가 자동 판정 기준을 충족하면 뒤 단계의 복사본이나 실행별 우선순위가 선택을 덮어쓰지 않습니다. 앞 단계가 자동 기준 미만일 때만 자동 기준 이상의 개별 초안이 판정 여유폭 이상 강한 경우 해당 초안 계보를 사용합니다. 정기 작업내역과 일본언론동향 양쪽에 모두 있으면 정기 경로를 선택하고 `일일일본동향=O`는 유지하되, 현재 원문을 직접 대조한 확인값은 일본 원문 유입을 확정할 수 있습니다.

```powershell
codex plugin marketplace upgrade foreign-news-history
```

## 데이터와 설정

플러그인에는 개인 이름, 작업 결과물, Google Sheets 문서 ID·URL 또는 인증 정보가 포함되지 않습니다. 실행 시 연결된 Google 계정에서 위 두 문서 이름을 찾고 탭·헤더 구조로 검증합니다. 같은 이름의 후보를 구조로 하나까지 확정할 수 없으면 임의 선택하지 않고 사용자 확인을 요청합니다.
